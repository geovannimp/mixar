# Beats f32 Wire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Widen `SetAutoLoop` / `BeatJump` / `BeginLoopRoll` beats from integers to `f32`, including controller decimal map args and FE zod.

**Architecture:** Plain `f32` on `CmdBody` and engine methods; controller adds `ArgValue::Float` + `require_f32`; validate finite / `> 0` (auto, roll) / `!= 0` (jump) at catalog and engine.

**Tech Stack:** Rust (`engine-api`, `engine-core`, `controller`), TypeScript zod (`wire.ts`), cargo/vitest tests.

## Global Constraints

- No `1/4` rational grammar.
- No newtype wrapper — bare `f32`.
- Do not change hot-cue `loop_length_beats`.
- Integers in map args must still work (`beats:4` → f32 `4.0`).

**Interfaces:**

- [ ] **Step 1:** Change `ArgValue` / `ActionArgs` derives from `Eq` to drop `Eq` (keep `PartialEq`). Add `Float(f32)`.

- [ ] **Step 2:** In `parse_arg_value`, after `i64` parse, try `value.parse::<f32>()` and accept only if `is_finite()` (reject bare `.` garbage via parse failure). Do not accept idents that look like floats.

- [ ] **Step 3:** Add:

```rust
pub fn require_f32(&self, key: &str) -> Result<f32, LoadError> {
    match self.map.get(key) {
        Some(ArgValue::Float(v)) => Ok(*v),
        Some(ArgValue::Int(v)) => Ok(*v as f32),
        Some(_) => Err(LoadError::Validation(format!("arg `{key}` must be a number"))),
        None => Err(LoadError::Validation(format!("missing required arg `{key}`"))),
    }
}
```

- [ ] **Step 4:** Catalog `auto_loop`: `require_f32`; reject if `!finite || <= 0`. `beat_jump`: reject if `!finite || == 0`.

- [ ] **Step 5:** `resolve_action` for `auto_loop` / `beat_jump`: use `require_f32` (same guards); pass `beats` into `CmdBody` without `as u32`/`as i32`.

- [ ] **Step 6:** Tests: parse `beats:0.25`, `beats:-0.5`; catalog rejects `0` / `nan` if representable; resolve emits `f32`. Keep existing int tests.

- [ ] **Step 7:** `cargo test --manifest-path crates/Cargo.toml -p controller`
