# Stem demo asset

Place an NI Stem file here as:

```text
track.stem.mp4
```

The marketing stems player loads `/demo/track.stem.mp4` in the browser via
[`stem-mp4`](https://github.com/monteslu/stem-mp4). The file is not committed
(see repo `.gitignore`) — drop it locally before `website:dev` / deploy.
