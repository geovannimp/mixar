Everything in the **Deck** section seeds new decks. A track already loaded keeps what it was loaded with until you change it on the deck itself. **Save** writes these preferences and restarts the audio engine when it is running.

The deck count and the on-screen panels live under [**Layout**](/docs/users/settings/interface), because they shape the whole page rather than a deck's defaults.

## Mixer → Crossfader

Card subtitle: "The curve the crossfader follows, plus the two performance flags."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Default curve** | select | **Constant power** / **Linear** / **Fast cut**, plus any custom group or curve set in your library | Constant power | Gain law both sides follow as the fader moves. Constant power keeps the sum of both channels even through the middle; linear is the plain `1 - x` / `x` crossfade; fast cut stays at full gain near the ends and swaps over quickly. |
| **Hamster (swap A and B)** | checkbox | on / off | off | Swaps the A and B gains without mirroring the fader position. |
| **Disable the crossfader** | checkbox | on / off | off | Bypasses the curve and leaves both sides at full gain; deck **THRU** assignments still bypass the fader. |

Changing any of these restarts the audio engine, because they seed the mixer it builds. A controller can change the active curve live without a restart (see [crossfader curves](/docs/developers/mixer/overview#crossfader-curves)).

### Custom curves

**Settings → Curves** is the visual editor for the same curve library. Create an A/B curve to edit deck A and deck B separately, or a scalar curve for a single control. Drag points on the chart, tap the chart or use **Add point** to insert one, and pick the interpolation for each segment: linear, exponential, logarithmic, or cubic Bézier. A curve set sweeps between two or more A/B curves; drag its **Morph** slider to preview the blend. Curve and set ids are stable snake_case, so controller mappings can select them by id; deleting a curve that a set or the default selection uses is blocked until the reference is removed. **Import VirtualDJ** turns a `crossfaderCurve`/`crossfaderCustom` pair into an editable native A/B curve, and **Export to VirtualDJ** writes the selected curve back as a `crossfaderCustom` point script.

## Mixer → Volume normalizer

Card subtitle: "Match analyzed tracks to a target loudness."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Volume normalizer** | header switch | on / off | on | Enables the loudness match for analyzed tracks. With it off, **Target LUFS** is hidden. |
| **Target LUFS** | stepper | −24.0 to −9.0 in 0.5 steps | −18.0 | Perceived loudness the normalizer aims at. |

The gain it applies shows in the deck's **Gain** popover as **Auto gain**. Tracks without a loudness measurement are left alone, so analyze a track before you rely on it. See [Analysis](/docs/users/library/analysis).

## Mixer → Sampler routing

Card subtitle: "Where sampler hits enter the signal path, relative to the channel strip."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Sampler strip route** | select | **Before channel strip** / **After channel strip** | Before channel strip | Whether the channel strip processes sampler hits. |

**Before channel strip** mixes sampler hits into the deck's dry signal before EQ, filter and fader, so those act on the hits too. **After channel strip** sums them past that processing, so the channel's EQ, filter and fader leave them alone. The crossfader and master still apply.

## Mixer → Realtime Stems

Card description: "Separates tracks without cached stems while they play. Tracks with offline stems always take priority." Under it the card adds **Not recommended.** and "Quality is lower and it uses a CPU core."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Realtime Stems** | header switch | on / off | off | Separates tracks that have no stem cache while they play. |

Offline stems always win, so turning this on never changes a track that already has a stem cache. What separation costs and where the files go: [Generate stems](/docs/users/stems/generate).

## Deck → Jog wheel

Card subtitle: "Defaults for top (touch) and outer (freewheel) platter policy."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Top jog mode** | select | **Vinyl (scratch)** / **Pitch bend** / **Ignore** | Vinyl (scratch) | Behaviour of the platter's top surface. **Ignore** makes that surface inert. |
| **Outer jog mode** | select | **Vinyl (scratch)** / **Pitch bend** / **Ignore** | Pitch bend | Behaviour of the outer ring. An outer jog set to **Pitch bend** scratches while the deck is paused. |

## Deck → Vinyl brake pause

Card subtitle: "Pause spins the deck down like a turntable instead of cutting instantly."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Brake on pause** | header switch | on / off | off | Off means pause cuts. |
| **Stop time** | stepper | 0.05–3.0 s in 0.05 steps | 0.50 s | Hidden while the brake is off. Hint: "How long the platter takes to stop after pause." |

## Deck → Tempo and Key

Card subtitle: "Default pitch-fader range and key lock for new decks."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Default tempo range** | select | ±6%, ±10%, ±16%, ±25% | ±6% | Pitch-fader range a freshly loaded deck starts with. |
| **Default key lock** | checkbox (**Key lock**) | on / off | off | Key lock state a freshly loaded deck starts with. |

The key lock hint is "Tempo-only pitch when on (time-stretch). Off = vinyl tempo." Both values are the ones a freshly loaded deck starts with. The tempo range key on the deck still cycles through the ladder.

## Deck → Sampler

Card subtitle: "Default play mode for inherit banks and default bank per deck."

| Control | Type | Values | Default | Effect |
| --- | --- | --- | --- | --- |
| **Sampler play mode** | select | **Oneshot** / **Hold** / **Loop** | Oneshot | Play mode for hits in inherit banks. |
| **Deck A default sampler bank** | select | a bank, or **None** | None | Bank deck A's pads start on. |
| **Deck B default sampler bank** | select | a bank, or **None** | None | Bank deck B's pads start on. |
| **Deck C default sampler bank** | select | a bank, or **None** | None | Bank deck C's pads start on. Shown in a four-deck layout. |
| **Deck D default sampler bank** | select | a bank, or **None** | None | Bank deck D's pads start on. Shown in a four-deck layout. |

The app shows one default-bank select per deck that currently exists, so a four-deck layout shows four. Options are your banks plus **None**.

Sampler hits are routed by **Sampler strip route** in the Mixer section above. The pads themselves are covered in [Sampler](/docs/users/performance-pads/sampler). Jog, tempo and brake behaviour on the deck is covered in [Jog and waveform](/docs/users/decks/jog-and-waveform) and [Transport](/docs/users/decks/transport).
