Select the **Sample** tab and the eight pads trigger short pieces of audio from the deck's sampler, alongside the track that is playing. The audio can be a vocal stab, a drum hit, or an acapella.

## Before you start

- A track is loaded on the deck. With no track the pads are disabled: [Overview](/docs/users/performance-pads).
- The sample you want is in the library, ready to drag.

## Assign a sample

1. Select the **Sample** tab.
2. **Drag a track from the library onto a pad.**
3. Drag another track onto an assigned pad to replace the sample.

## Banks

Samples are organised in **banks** of eight slots. The settings button lists the available banks, and the active bank's name is shown in the pads header.

That menu also opens the bank settings:

- **Name**: rename the bank.
- **Play mode**: how the pads in this bank trigger.

| Play mode | Behaviour |
| --- | --- |
| **Oneshot** | Starts a single, non-looping play that runs to the end of the sample; release does not stop it |
| **Hold** | Plays while the pad is held and stops on release |
| **Loop** | Repeats while the pad is held and stops on release |
| **Default** | Follows **Sampler play mode** in Settings → Deck, which is **Oneshot** unless you change it |

## Check the result

- An assigned pad shows the sample's name and length.
- The pads header shows the active bank's name.

## Clear a sample

Hold **Shift** while pressing an assigned pad to **clear** the sample, leaving the pad empty.

## If a pad does not fire

- **The pad is empty**: drag a library track onto it.
- **The sample stops on release**: the bank is in **Hold** or **Loop**. A bank on **Default** follows the **Sampler play mode** in Settings → Deck, which can also be **Hold** or **Loop**. Set the bank's play mode to **Oneshot** if it should run to the end.
