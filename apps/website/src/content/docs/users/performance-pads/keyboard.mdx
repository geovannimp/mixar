Select the **Keys** tab and the eight pads play a single hot cue at eight different pitches. It suits dropping a vocal or a stab in key over a mix without editing the track.

## Root hot cue

Keyboard pads always play from a **root hot cue**. Pick the root from the settings button in the pads header.

Only cues that are actually set on the track can be chosen. Set one in [Hot Cues](/docs/users/performance-pads/hot-cues) first if the list is empty.

## Pad behaviour

| Action | Result |
| --- | --- |
| Hold a pad | Plays the root hot cue at that pad's pitch |
| Release the pad | Stops and returns to the root position; the pitch change is temporary and playback continues as before |
| Release one pad while another is held | The held pad's pitch stays in effect |
| Press any pad | The tempo does not change, only the pitch |

## Pages

The pads cover one octave of semitones at a time, spread over **four pages**, starting on page 2. The pads header shows the range the current page covers.

| Page | Label | Pads 1–8 |
| --- | --- | --- |
| 1 | +8…+12 | +8, +9, +10, +11, +12, empty, empty, empty |
| 2 (default) | 0…+7 | 0, +1, +2, +3, +4, +5, +6, +7 |
| 3 | -1…-8 | -8, -7, -6, -5, -4, -3, -2, -1 |
| 4 | -9…-12 | empty, empty, empty, empty, -12, -11, -10, -9 |

Blank pads on a page do nothing. Pages wrap from 4 back to 1.

The settings button in the header lists every page if you want to jump straight to one.

## Shortcuts

| Keys | Action |
| --- | --- |
| **Shift** + **pads 1–6** | Delete that hot cue from the track |
| **Shift** + **pad 7 / pad 8** | Move to the next / previous page |

## If a pad plays no cue

If the root list is empty the pads still shift the deck's key, but there is no cue to play. The settings button shows **No hot cues** in that case. Set one in [Hot Cues](/docs/users/performance-pads/hot-cues) first.
