Select the **Jump** tab and each pad moves the playhead by a fixed number of beats. Pads 1–4 move forward, pads 5–8 move back:

| Pad | Jump |
| --- | --- |
| 1 | +1 beat |
| 2 | +2 beats |
| 3 | +4 beats |
| 4 | +8 beats |
| 5 | −1 beat |
| 6 | −2 beats |
| 7 | −4 beats |
| 8 | −8 beats |

**Tap a pad** once to jump by that amount. Unlike Loop Roll, there is nothing to hold — the jump happens on press.

This is a fast way to skip an intro, drop back a bar before a breakdown, or pull the track back in time when you have drifted out of a mix.

## Requirements

Jumps are measured in beats, so the track needs an analysed **BPM**. With **Quantize** enabled the playhead lands on the beat rather than between beats.
