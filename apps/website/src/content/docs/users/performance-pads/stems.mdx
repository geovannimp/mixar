Select the **Stems** tab and the pads control the separated layers of the loaded track: **Drums**, **Bass**, **Other**, and **Vocals**.

## The pads

The top row mutes and unmutes, the bottom row isolates:

| Pads 1–4 | Pads 5–8 |
| --- | --- |
| `mute` drums | `solo` drums |
| `mute` bass | `solo` bass |
| `mute` other | `solo` other |
| `mute` vocals | `solo` vocals |

**Mute** — press to silence that layer, press again to bring it back. The pad lights while the layer is muted.

**Isolate** — press to hear only that layer with the other three silenced. Press the same pad again to clear the isolation and return to the mix of muted and unmuted layers.

If the loaded track has no stems yet, the pads stay disabled and do nothing. The track still plays normally. While Mixar is separating a track, the pads show **STEMS GENERATING…**.
