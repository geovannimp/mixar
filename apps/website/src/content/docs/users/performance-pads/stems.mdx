Select the **Stems** tab and the pads control the separated layers of the loaded track: **Drums**, **Bass**, **Other**, and **Vocals**.

## Before you start

- A track is loaded on the deck. With no track the pads are disabled: [Overview](/docs/users/performance-pads).
- The track has stems: an [NI Stem file](/docs/users/stems/native-ni) already loaded, stems [generated](/docs/users/stems/generate) for it, or **Settings → Mixer → Realtime Stems** enabled so Mixar separates it live. Realtime pads switch on once the first window is covered.

## The pads

The top row mutes and unmutes, the bottom row isolates:

| Pads 1–4 | Pads 5–8 |
| --- | --- |
| `mute` drums | `solo` drums |
| `mute` bass | `solo` bass |
| `mute` other | `solo` other |
| `mute` vocals | `solo` vocals |

## Mute

1. Select the **Stems** tab.
2. Press a pad in the top row to silence that layer.
3. Press the same pad again to bring the layer back.

## Isolate

1. Press a pad in the bottom row to hear only that layer, with the other three silenced.
2. Press the same pad again to clear the isolation and return to the mix of muted and unmuted layers.

## Check the result

The pad lights while the layer is muted.

## If the pads are disabled

If the loaded track has no stems yet, the pads stay disabled and do nothing. The track still plays normally.

While Mixar is separating a track, the pads show **STEMS GENERATING…**.

## Stem EQ on the mixer knobs

Press **ST** in the deck header to route that deck's `HI`, `MID`, and `LOW` knobs to the stems instead of the channel EQ; the labels change:

| Knob label | Controls |
| --- | --- |
| `VOC` | Vocals |
| `B/O` | Bass and Other together |
| `DRM` | Drums |

Center is the normal stem mix. Turning a knob left fades that group out; turning it right isolates that group by fading the other two out. Mute and isolate pads still apply on top of the knob positions.

The toggle is per deck: it works with any pad mode selected, and pressing **ST** again returns the knobs to the channel EQ. **ST** is only available while the deck actually plays stems, so a track without stems still plays normally and the knobs stay on the channel EQ.

Live separation runs at about real time on a CPU. When it falls behind, the deck keeps playing the normal mix: the knobs temporarily return to the channel EQ, and **ST** goes unlit until stems catch up — the toggle itself stays on, so the routing resumes on its own. Cached stems (generated ahead of time and stored with the track) have no such limit.

The same command is available to controller mappings, see [`toggle_stem_eq`](/docs/developers/midi-mappings/actions).
