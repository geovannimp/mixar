Select the **Roll** tab and each pad is a temporary loop of a fixed length, starting from wherever the playhead is when you press it.

## Using a pad

**Hold the pad** to start the loop and **release** it to end it. Each pad is labelled with its loop length:

| Pad | Length |
| --- | --- |
| 1 | 1/32 beat |
| 2 | 1/16 beat |
| 3 | 1/8 beat |
| 4 | 1/4 beat |
| 5 | 1/2 beat |
| 6 | 1 beat |
| 7 | 2 beats |
| 8 | 4 beats |

Holding several pads at once re-triggers the loop from the current position at the length of the most recently pressed pad.

## What happens when you release

The loop ends and playback continues from the position the track would have reached if the loop had never started. If you had a loop set up before pressing the pad, that loop is restored.

## Requirements

The loop length is measured in beats, so the track needs an analysed **BPM**. With **Quantize** enabled the loop starts on the beat rather than mid-beat.
