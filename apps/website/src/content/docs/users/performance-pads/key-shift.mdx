Select the **Shift** tab and the pads change the pitch of everything playing on that deck. It is a way to bend a track into the key of what is next, or to sing along without transposing the track itself.

## Before you start

- A track is loaded on the deck. With no track the pads are disabled: [Overview](/docs/users/performance-pads).

## Set an offset

1. Select the **Shift** tab.
2. **Tap a pad** to set the pitch offset to that value.

The offset is latched: it stays until you change or reset it.

The offset is expressed in **semitones** above or below the track's own key, and covers **±16 semitones** in total. It is a performance setting: the track's saved key is never altered, and nothing is written back to your library.

This is separate from the tempo fader: the pitch moves without the tempo changing.

## Pages

Key Shift has **five pages**. Pages 1–4 hold the same semitone values as [Keyboard](/docs/users/performance-pads/keyboard) mode; page 5 is a **UTIL** page of shortcut pads:

| Page | Label | Pads 1–8 |
| --- | --- | --- |
| 1 | +8…+12 | +8, +9, +10, +11, +12, empty, empty, empty |
| 2 (default) | 0…+7 | 0, +1, +2, +3, +4, +5, +6, +7 |
| 3 | -1…-8 | -8, -7, -6, -5, -4, -3, -2, -1 |
| 4 | -9…-12 | empty, empty, empty, empty, -12, -11, -10, -9 |
| 5 | UTIL | see below |

The settings button lists every page. The five pages wrap from 5 back to 1.

## Page 5: utility pads

| Pad | Action |
| --- | --- |
| 1 | **RESET**: return the offset to zero |
| 2 | **DOWN**: lower the current offset by one semitone |
| 3 | -5 semitones |
| 4 | -12 semitones |
| 5 | **SYNC**: no action yet |
| 6 | **UP**: raise the current offset by one semitone |
| 7 | +7 semitones |
| 8 | +12 semitones |

Blank pads on a page do nothing.

## Check the result

The pad matching the current offset is highlighted. An offset with no absolute pad on the current page, such as ±13 to ±16, highlights nothing.

## If the offset is wrong

- **Start over**: page 5, pad 1, **RESET**.
- **One semitone off**: page 5, pad 2 **DOWN** or pad 6 **UP**.

## Shortcut

Hold **Shift** while pressing **pad 7 / pad 8** to move to the next / previous page.
